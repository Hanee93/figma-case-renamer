# 커뮤니티 등록 문구

Figma Community 등록 화면에 그대로 붙여넣을 수 있게 정리한 문구입니다.

## 이름
레이어이름 정리

## 태그라인 (짧은 소개)
한글 레이어 이름을 camelCase · snake_case 등 영어 네이밍 컨벤션으로 한 번에 정리

## 설명 (한국어)
디자인 파일의 레이어 이름이 "로그인 버튼", "Frame 12", "확인버튼" 처럼 제각각인가요?
레이어이름 정리는 선택한 레이어의 이름을 개발 컨벤션에 맞게 한 번에 바꿔줍니다.

**케이스 변환**
camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE, Title Case 중 하나를 고르면 끝.
"HTMLParser" 같은 약어도 올바르게 나눠서 html_parser 로 만듭니다.

**한글 단어를 한 번만 입력**
선택한 레이어 전체에서 한글 단어를 모아 중복 없이 보여줍니다.
"버튼 → button" 한 번만 적으면 "로그인 버튼", "확인 버튼", "닫기 버튼"이 전부 바뀝니다.
입력한 단어는 저장되어 다음에 플러그인을 열면 그대로 채워져 있습니다.
"취소버튼"처럼 붙어 있는 이름도 "취소", "버튼"을 따로 적으면 나눠서 적용됩니다.

**자동 번호 정리**
Figma 가 붙이는 "Frame 12", "Rectangle 3" 의 숫자를 지우거나, 선택 순서대로 1, 2, 3… 으로 다시 매깁니다.

**안전하게**
- 적용 전에 바뀔 이름을 전부 미리 보여줍니다.
- 컴포넌트 variant("Size=Large") 와 인스턴스는 건드리지 않습니다.
- "Button / Primary" 같은 슬래시 그룹 구분은 유지합니다.
- 적용 후 Cmd+Z 한 번으로 전체를 되돌릴 수 있습니다.
- 네트워크를 전혀 사용하지 않습니다. 디자인이 외부로 나가지 않습니다.

## Description (English)
Rename selected layers to a consistent naming convention in one go — with first-class support for Korean layer names.

- Convert to camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE or Title Case
- Korean words are collected once across the selection; type the English for "버튼 → button" a single time and every layer containing it is renamed. Your dictionary is remembered for next time.
- Clean up Figma's auto numbers ("Frame 12", "Rectangle 3"): strip them or renumber sequentially
- Full preview before applying, variants and instances are left untouched, "/" groups are preserved, and one Cmd+Z undoes everything
- No network access. Nothing leaves your file.
